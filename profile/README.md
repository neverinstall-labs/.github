# Neverinstall Labs

Open-source tools and guides for teams that plan, evaluate, migrate and run on-premises infrastructure:
virtualisation, hyperconverged storage, networking, GPUs and virtual desktops.

The tools are vendor-neutral. They work whichever platform you choose, including VMware, Nutanix, Proxmox,
OpenShift Virtualization, Hyper-V and our own.

## How the tools work

- **They run locally.** Browser tools process files in the browser. Command-line tools run on your machine. No
  inventory, result or telemetry is sent to us.
- **Tools that run on your systems are read-only.** Each README states what the tool reads and confirms that it
  changes nothing.
- **Assumptions are visible.** Formulas and vendor rules live in versioned files. Each entry cites its source and
  the date it was checked. Corrections are welcome as pull requests.
- **Results are estimates.** Measure on your own hardware before you rely on a number.
